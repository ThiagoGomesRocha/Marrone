Marrone is een nieuwe en innovatieve API-client, gericht op het revolutioneren van de status quo die wordt vertegenwoordigd door Postman en vergelijkbare tools.

Marrone slaat je collecties direct op in een map op je bestandssysteem. We gebruiken een platte tekst opmaaktaal, Bru, om informatie over API-verzoeken op te slaan.

Je kunt Git of elke versiebeheertool naar keuze gebruiken om samen te werken aan je API-collecties.

Marrone is uitsluitend offline. Er zijn geen plannen om ooit cloud-synchronisatie aan Marrone toe te voegen. We waarderen je gegevensprivacy en geloven dat deze op je apparaat moet blijven. Lees onze langetermijnvisie [hier](https://github.com/marrone/marrone/discussions/269)

### Installatie

Marrone is beschikbaar als binaire download [op onze website](https://www.marrone.com/downloads) voor Mac, Windows en Linux.

Je kunt Marrone ook installeren via pakketbeheerders zoals Homebrew, Chocolatey, Scoop, Snap, Flatpak en Apt.

```sh
# Op Mac via Homebrew
brew install marrone

# Op Windows via Chocolatey
choco install marrone

# Op Windows via Scoop
scoop bucket add extras
scoop install marrone

# Op Windows via winget
winget install Marrone.Marrone

# Op Linux via Snap
snap install marrone

# Op Linux via Flatpak
flatpak install com.marrone.Marrone

# Op Linux via Apt
sudo mkdir -p /etc/apt/keyrings
sudo apt update && sudo apt install gpg curl
curl -fsSL "https://keyserver.ubuntu.com/pks/lookup?op=get&search=0x9FA6017ECABE0266" \
  | gpg --dearmor \
  | sudo tee /etc/apt/keyrings/marrone.gpg > /dev/null
sudo chmod 644 /etc/apt/keyrings/marrone.gpg
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/marrone.gpg] http://debian.marrone.com/ marrone stable" \
  | sudo tee /etc/apt/sources.list.d/marrone.list
sudo apt update && sudo apt install marrone
```
