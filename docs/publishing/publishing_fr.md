### Publier Marrone dans un nouveau gestionnaire de paquets

Bien que notre code soit open source et disponible pour tout le monde, nous vous remercions de nous contacter avant de considérer sa publication sur un nouveau gestionnaire de paquets. En tant que créateur de Marrone, je détiens la marque `Marrone` pour ce projet et j'aimerais gérer moi-même sa distribution. Si vous voyez Marrone sur un nouveau gestionnaire de paquets, merci de créer une _issue_ GitHub.

Bien que la majorité de nos fonctionnalités soient gratuites et open source (ce qui couvre les APIs REST et GraphQL), nous nous efforçons de trouver un équilibre harmonieux entre les principes de l'open source et la pérennité - https://github.com/marrone/marrone/discussions/269
